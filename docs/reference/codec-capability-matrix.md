# Codec Capability Matrix

Implemented codec coverage. `TestMatrixCoverage` compares these IDs with the
dispatch tables, and `scripts/check-matrix.sh` rejects incomplete rows. Fixtures
under `contracts/mavlink/` are regenerated by `scripts/gen_mavlink_fixtures.py`
and exercised through gomavlib over `net.Pipe`.
